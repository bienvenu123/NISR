# District boundary data

`rwanda_districts.geojson` was retrieved from the Rwanda national geodata ArcGIS FeatureServer district layer on 2026-10-28. The service layer identifies NISR and the Rwanda Land Authority in its copyright metadata and describes the boundaries as part of the national base map review. District codes (`dist_code`) match the EICV7 codes. Geometry was requested in EPSG:4326 for the dashboard.

Source: https://geodata.rw/server/rest/services/basemap/District_Boundary/FeatureServer/0
